# ISL-Sense — Real-Time Indian Sign Language Recognition

An end-to-end, landmark-based pipeline for training an Indian Sign Language (ISL) recognition model and running it live from a webcam. This project follows the approach developed in AI4Bharat's **[INCLUDE](https://github.com/AI4Bharat/INCLUDE)** and **[OpenHands](https://github.com/ai4bharat/openhands)** research (pose/hand keypoints → sequence model), rather than raw-video CNNs, because keypoints train faster, generalize across diverse backgrounds and lighting, and run with low latency on standard CPU and edge devices.

## 1. Project Overview

The objective is to recognize isolated Indian Sign Language gestures:
1. **Offline Processing:** Convert video clips into spatial-temporal sequences of skeletal keypoints (shoulders, elbows, wrists, hands, and facial cues).
2. **Coordinate Normalization:** Center coordinates at the torso and scale by shoulder distance to achieve translation and distance invariance.
3. **Sequence Modeling:** Train a neural network (BiLSTM, Transformer Encoder, or Hybrid) to classify the dynamic motion trajectories.
4. **Live Interaction:** Connect a webcam feed to an OpenCV pipeline that extracts landmarks in real time, buffers a temporal window, and outputs the detected word as a subtitle overlay.

## 3. Landmark Feature Representation

Each frame is represented as a normalized 1D float32 vector saved in `.npy` files with shape `(T_frames, feature_dim)`:

### Feature Breakdown
```text
[ pose (33 × 3 = 99) | left_hand (21 × 3 = 63) | right_hand (21 × 3 = 63) | face (468 × 3 = 1404)* | flags (3) ]
```

- **Pose (99 dims):** 33 body landmarks $\times (x, y, z)$ (wrists, elbows, shoulders, nose).
- **Left & Right Hands (126 dims):** 21 landmarks $\times 3$ coordinates per hand.
- **Face Mesh (1404 dims, optional):** 468 facial mesh landmarks $\times 3$.
- **Detection Flags (3 dims):** Binary flags `[pose_detected, left_hand_detected, right_hand_detected]`.

| Configuration | Feature Dim per Frame | Recommended For |
|---|---|---|
| **Pose + Hands + Flags** (`include_face=False`) | **234** | Fast training, real-time CPU webcam inference (Recommended) |
| **Pose + Hands + Face + Flags** (`include_face=True`) | **1,632** | Research, subtle facial grammatical expressions |

## 4. Best Practices (AI4Bharat & OpenHands Insights)

1. **Torso-Centered & Scale-Invariant Normalization:**
   - **Anchor:** Center coordinates on the mid-shoulder point: `(left_shoulder + right_shoulder) / 2`.
   - **Scale:** Divide coordinates by shoulder Euclidean distance: `||left_shoulder - right_shoulder||`.
   - Makes the model invariant to camera distance and signer position in the frame.
2. **Explicit Handling of Missing Hands:**
   - One-handed signs leave the inactive hand invisible or outside the frame. Fill missing hand landmarks with zeros and pass visibility flag indicators so attention mechanisms ignore absent keypoints.
3. **Temporal Resampling & Padding:**
   - Sign durations vary (typically 30–90 frames). Resample sequences to a standard length (e.g. $T = 40$) using linear interpolation, or pad shorter sequences with zeros and apply a boolean sequence mask.
4. **Data Augmentation:**
   - Apply temporal speed jitter ($\pm 15\%$) and subtle spatial scaling/rotation ($\pm 10^\circ$). Do not horizontally flip signs that are handedness-dependent.
5. **Real-Time Live Stabilization:**
   - Maintain a rolling queue (sliding window) of $N=40$ frames.
   - Run inference periodically (e.g., every 2–3 frames) rather than every single frame.
   - Smooth output using majority voting over the last 5 window predictions and a confidence threshold ($p \ge 0.75$).

## 6. Complete Code & Workflow

Here are the modular scripts to extract landmarks, load data, train the model, and run live webcam recognition.

### A. Landmark Extraction (`extract_landmarks.py`)
Processes videos in **`raw_data/`** and saves `.npy` sequences into **`landmarks/`**:

```python
import os
import cv2
import numpy as np
import mediapipe as mp
from pathlib import Path
from tqdm import tqdm

class LandmarkExtractor:
    def __init__(self, include_face=False):
        self.include_face = include_face
        self.mp_holistic = mp.solutions.holistic.Holistic(
            static_image_mode=False,
            model_complexity=1,
            min_detection_confidence=0.5,
            min_tracking_confidence=0.5
        )
        self.origin = np.zeros(3, dtype=np.float32)
        self.scale = 1.0

    def process_frame(self, frame_bgr):
        rgb = cv2.cvtColor(frame_bgr, cv2.COLOR_BGR2RGB)
        res = self.mp_holistic.process(rgb)

        def to_arr(lms, count):
            if lms is None:
                return np.zeros((count, 3), dtype=np.float32)
            return np.array([[lm.x, lm.y, lm.z] for lm in lms.landmark[:count]], dtype=np.float32)

        pose = to_arr(res.pose_landmarks, 33)
        lh = to_arr(res.left_hand_landmarks, 21)
        rh = to_arr(res.right_hand_landmarks, 21)

        pose_ok = res.pose_landmarks is not None
        lh_ok = res.left_hand_landmarks is not None
        rh_ok = res.right_hand_landmarks is not None

        # Torso calibration
        if pose_ok:
            ls, rs = pose[11], pose[12]
            width = float(np.linalg.norm(ls - rs))
            if width > 1e-3:
                self.origin = (ls + rs) / 2.0
                self.scale = width

        def norm(arr):
            return ((arr - self.origin) / self.scale).astype(np.float32)

        parts = [norm(pose).reshape(-1), norm(lh).reshape(-1), norm(rh).reshape(-1)]
        if self.include_face:
            face = to_arr(res.face_landmarks, 468)
            parts.append(norm(face).reshape(-1))
        parts.append(np.array([pose_ok, lh_ok, rh_ok], dtype=np.float32))

        return np.concatenate(parts, axis=0)

    def extract_video(self, video_path):
        cap = cv2.VideoCapture(str(video_path))
        frames = []
        while cap.isOpened():
            ret, frame = cap.read()
            if not ret:
                break
            frames.append(self.process_frame(frame))
        cap.release()
        return np.stack(frames, axis=0) if frames else None

    def close(self):
        self.mp_holistic.close()

def batch_extract(raw_root="raw_data", save_root="landmarks", include_face=False):
    extractor = LandmarkExtractor(include_face=include_face)
    raw_path = Path(raw_root)
    save_path = Path(save_root)
    video_files = list(raw_path.rglob("*.MOV")) + list(raw_path.rglob("*.mp4"))

    print(f"Found {len(video_files)} videos in {raw_root}. Extracting landmarks into {save_root}...")
    for v_path in tqdm(video_files):
        rel = v_path.relative_to(raw_path).with_suffix(".npy")
        out_file = save_path / rel
        if out_file.exists():
            continue
        out_file.parent.mkdir(parents=True, exist_ok=True)
        feats = extractor.extract_video(v_path)
        if feats is not None:
            np.save(out_file, feats)
    extractor.close()

if __name__ == "__main__":
    # Start extraction (include_face=False gives 234 features for fast training)
    batch_extract(raw_root="raw_data", save_root="landmarks", include_face=False)
```

### B. Dataset & Preprocessing (`dataset.py`)
Loads `.npy` files from **`landmarks/`**, resamples them to a fixed sequence length, and prepares batches for PyTorch:

```python
import torch
from torch.utils.data import Dataset
import numpy as np
from pathlib import Path

def resample_sequence(seq, target_len=40):
    curr_len = seq.shape[0]
    if curr_len == target_len:
        return seq
    indices = np.linspace(0, curr_len - 1, target_len)
    resampled = np.zeros((target_len, seq.shape[1]), dtype=np.float32)
    for dim in range(seq.shape[1]):
        resampled[:, dim] = np.interp(indices, np.arange(curr_len), seq[:, dim])
    return resampled

class ISLLandmarkDataset(Dataset):
    def __init__(self, npy_files, labels, target_len=40, augment=False):
        self.npy_files = npy_files
        self.labels = labels
        self.target_len = target_len
        self.augment = augment

    def __len__(self):
        return len(self.npy_files)

    def __getitem__(self, idx):
        data = np.load(self.npy_files[idx])
        data = resample_sequence(data, self.target_len)

        if self.augment:
            # Subtle coordinate jitter
            noise = np.random.normal(0, 0.01, data.shape).astype(np.float32)
            data = data + noise

        return torch.tensor(data, dtype=torch.float32), torch.tensor(self.labels[idx], dtype=torch.long)
```

### C. Sequence Model Architecture (`model.py`)
A hybrid architecture combining a local temporal LSTM with a Transformer Encoder:

```python
import torch
import torch.nn as nn

class HybridSignModel(nn.Module):
    def __init__(self, input_dim=234, num_classes=8, d_model=128, nhead=4, num_transformer_layers=2):
        super().__init__()
        self.input_proj = nn.Linear(input_dim, d_model)
        
        # 1. Local motion extractor (Bi-LSTM)
        self.lstm = nn.LSTM(d_model, d_model // 2, num_layers=1, batch_first=True, bidirectional=True)
        
        # 2. Global context extractor (Transformer Encoder)
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model, 
            nhead=nhead, 
            dim_feedforward=256, 
            dropout=0.2, 
            batch_first=True
        )
        self.transformer = nn.TransformerEncoder(encoder_layer, num_layers=num_transformer_layers)
        
        # 3. Classification Head
        self.classifier = nn.Sequential(
            nn.LayerNorm(d_model),
            nn.Dropout(0.3),
            nn.Linear(d_model, num_classes)
        )

    def forward(self, x):
        # x shape: (Batch, Sequence_Len, input_dim)
        x = self.input_proj(x)
        lstm_out, _ = self.lstm(x)
        trans_out = self.transformer(lstm_out)
        pooled = torch.mean(trans_out, dim=1)
        return self.classifier(pooled)
```

### D. Training Loop (`train.py`)
Trains directly on the extracted categories in **`landmarks/`**:

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from pathlib import Path
from sklearn.model_selection import train_test_split
# from dataset import ISLLandmarkDataset
# from model import HybridSignModel

def train_isl(landmarks_dir="landmarks"):
    root = Path(landmarks_dir)
    # Find all sign category directories
    class_folders = sorted([cf for cf in root.rglob("*") if cf.is_dir() and list(cf.glob("*.npy"))])
    class_to_idx = {cf.name: i for i, cf in enumerate(class_folders)}

    files, labels = [], []
    for cf in class_folders:
        for f in cf.glob("*.npy"):
            files.append(f)
            labels.append(class_to_idx[cf.name])

    print(f"Found {len(files)} landmark files across {len(class_folders)} classes: {list(class_to_idx.keys())}")

    if len(files) == 0:
        print("No landmark files found! Run extract_landmarks.py first.")
        return

    # Stratified train/validation split
    train_f, val_f, train_l, val_l = train_test_split(files, labels, test_size=0.2, stratify=labels, random_state=42)

    train_loader = DataLoader(ISLLandmarkDataset(train_f, train_l, target_len=40, augment=True), batch_size=16, shuffle=True)
    val_loader = DataLoader(ISLLandmarkDataset(val_f, val_l, target_len=40, augment=False), batch_size=16, shuffle=False)

    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model = HybridSignModel(input_dim=234, num_classes=len(class_folders)).to(device)

    criterion = nn.CrossEntropyLoss(label_smoothing=0.1)
    optimizer = torch.optim.AdamW(model.parameters(), lr=1e-3, weight_decay=1e-4)

    for epoch in range(1, 31):
        model.train()
        total_loss, correct, total = 0, 0, 0
        for x, y in train_loader:
            x, y = x.to(device), y.to(device)
            optimizer.zero_grad()
            out = model(x)
            loss = criterion(out, y)
            loss.backward()
            optimizer.step()

            total_loss += loss.item() * len(y)
            correct += (out.argmax(dim=1) == y).sum().item()
            total += len(y)

        # Validation
        model.eval()
        v_correct, v_total = 0, 0
        with torch.no_grad():
            for x, y in val_loader:
                x, y = x.to(device), y.to(device)
                out = model(x)
                v_correct += (out.argmax(dim=1) == y).sum().item()
                v_total += len(y)

        if epoch % 5 == 0 or epoch == 1:
            print(f"Epoch {epoch:02d} | Train Acc: {correct/total*100:.1f}% | Val Acc: {v_correct/v_total*100:.1f}%")

    torch.save(model.state_dict(), "isl_model.pth")
    print("Training complete. Model saved as isl_model.pth")

if __name__ == "__main__":
    train_isl("landmarks")
```

### E. Real-Time Webcam Inference (`live_predict.py`)
Connects to your webcam, buffers landmark frames in a circular queue, and renders the recognized sign as a live subtitle:

```python
import cv2
import numpy as np
import torch
import collections
# from extract_landmarks import LandmarkExtractor
# from model import HybridSignModel

def run_live(model_path="isl_model.pth", class_names=None, seq_len=40, threshold=0.75):
    if class_names is None:
        class_names = ["loud", "quiet", "happy", "sad", "Beautiful", "Ugly", "Deaf", "Blind"]

    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    model = HybridSignModel(input_dim=234, num_classes=len(class_names)).to(device)
    model.load_state_dict(torch.load(model_path, map_location=device))
    model.eval()

    extractor = LandmarkExtractor(include_face=False)
    cap = cv2.VideoCapture(0)

    frame_buffer = collections.deque(maxlen=seq_len)
    recent_preds = collections.deque(maxlen=5)
    current_label = "Waiting for gesture..."
    confidence = 0.0

    print("Webcam started. Press 'q' to exit.")
    while cap.isOpened():
        ret, frame = cap.read()
        if not ret:
            break

        frame = cv2.flip(frame, 1)
        h, w, _ = frame.shape

        # Extract features for current frame (234 floats)
        feat = extractor.process_frame(frame)
        frame_buffer.append(feat)

        # Run inference once buffer is full
        if len(frame_buffer) == seq_len:
            seq = np.array(frame_buffer)
            tensor_x = torch.tensor(seq, dtype=torch.float32).unsqueeze(0).to(device)
            with torch.no_grad():
                logits = model(tensor_x)
                probs = torch.softmax(logits, dim=1).cpu().numpy()[0]
                best_idx = np.argmax(probs)
                best_prob = probs[best_idx]

                if best_prob >= threshold:
                    recent_preds.append(class_names[best_idx])
                    # Temporal debounce: majority vote
                    majority = max(set(recent_preds), key=recent_preds.count)
                    current_label = majority
                    confidence = best_prob

        # Render subtitle overlay
        cv2.rectangle(frame, (0, h - 70), (w, h), (20, 20, 20), -1)
        cv2.putText(frame, f"Sign: {current_label} ({confidence*100:.1f}%)", 
                    (20, h - 25), cv2.FONT_HERSHEY_SIMPLEX, 0.9, (0, 255, 128), 2, cv2.LINE_AA)

        cv2.imshow("Indian Sign Language Recognition (Live)", frame)
        if cv2.waitKey(1) & 0xFF == ord('q'):
            break

    cap.release()
    cv2.destroyAllWindows()
    extractor.close()

if __name__ == "__main__":
    run_live()
```

## 7. Recommended Development Roadmap

1. **Step 1 — Landmark Extraction:**
   - Run `extract_landmarks.py` on a subset (e.g. `raw_data/Adjectives_1of8/`) or all categories in `raw_data/` to generate `landmarks/`.
2. **Step 2 — Prototyping & Verification:**
   - Train on the extracted subset using `train.py` to confirm that loss drops and accuracy converges.
3. **Step 3 — Scaling:**
   - Scale up to the 50 classes of INCLUDE-50 or all 263 classes.
4. **Step 4 — Live Testing:**
   - Run `live_predict.py` to test live sign recognition via your webcam with real-time subtitle feedback.
